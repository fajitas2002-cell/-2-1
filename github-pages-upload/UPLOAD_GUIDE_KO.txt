소아 투약안전 시뮬레이션 GitHub 업로드 안내

1. github-pages-upload.zip의 압축을 풉니다.
2. 압축을 푼 폴더 안의 파일과 assets 폴더를 모두 선택합니다.
3. GitHub 저장소 https://github.com/fajitas2002-cell/-2-1 에서
   Add file > Upload files를 선택합니다.
4. 선택한 파일을 저장소 최상위에 업로드하고 Commit changes를 누릅니다.
   github-pages-upload 폴더 자체를 올리는 것이 아니라 폴더 안의 내용물을 올려야 합니다.
5. 저장소 Settings > Pages로 이동합니다.
6. Build and deployment의 Source를 Deploy from a branch로 선택합니다.
7. Branch는 main, 폴더는 /(root)를 선택하고 Save를 누릅니다.
8. 약 1~5분 뒤 다음 주소로 접속합니다.

https://fajitas2002-cell.github.io/-2-1/

styles.css
app.js
